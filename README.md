# Апартамент 75 – Младост 4, София

Интериорен проект: 3D модел, технически чертежи, спецификации, списък за пазаруване и изходни файлове.

**Сайт:** https://outhenticltd.github.io/apartment-75/

- `viewer/` – 3D модел в браузъра (three.js, `model.glb`), отваряне на шкафове с докосване, измерване
- `plans/` – чертежи (PDF/PNG): разпределение, мебелировка, кухня, ТВ модул, гардероб/спалня, електро, ВиК, осветление
- `data/` – списък за пазаруване (JSON/CSV/Excel), всички обекти с размери (`scene_full.json`)
- `source/` – скриптове (Blender, одит, чертежи)
- Blender файлът е в **Releases**.
